# Curriculum roadmap

Implemented: the original Foundations, arrays, searching, sorting, lists, stacks, queues, BSTs and graphs, plus Hash Tables, Heaps and Priority Queues, Recursion, Two Pointers and Sliding Window. See [current module contracts](next-modules.md).

Future modules remain proposals, not functional catalog tiles:

- Balanced trees and ordered maps: rotations and invariants.
- Union-find: path compression and union by rank.
- Backtracking: state spaces, pruning and undo.
- Greedy algorithms: exchange arguments and counterexamples.
- Dynamic programming: memoization, tabulation and state definitions.
- Tries and string algorithms: prefix search, KMP and rolling hashes.
- Range queries: prefix sums, Fenwick and segment trees.
- Advanced graphs: topological order, MST, SCC, negative-weight paths and heap-based adjacency-list Dijkstra.

Each expansion needs a real bounded C implementation, topic-specific visualization, prerequisites and concepts, complete five-language examples, aligned assessments, additive persistence, native result oracles and actual Wasm/browser checks. No unmeasured educational or performance benefit is assumed.
